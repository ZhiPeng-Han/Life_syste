# 人生局势：从数据里看出主要矛盾，从各个角度看一个选择

> 你提的问题："研究一下 LifeOS 目前有没有人生局势分析的基础；结合科学、逻辑推演、哲学、周易、命理学，进一步研究天时和选择以及人生局势的分析判断，甚至可以学习马克思、毛泽东哲学。"

## 一、原来有什么基础

LifeOS 已经在记录"局势"需要的原材料，只是没有合在一起：

| 已有的 | 在哪里 | 能说明什么 |
|---|---|---|
| 各领域每周的时间预算与实际时间 | `rules.toml [domains]`、`timelog`、周复盘 | 投入是否和你说的优先级一致 |
| 领域之间的关系（协同、竞争、影响） | `relations`，初始假设见 `seed.py` | 哪些事在抢同一段时间 |
| 天下大势与各领域的顺逆 | `shi.momentum` | 外部环境 |
| 感受、签到（精力、心情、睡眠、和她的时间） | `states`、`checkins`、`review.patterns` | 你的状态和规律 |
| 决策日志与校准 | `decisions` | 你的判断准不准 |
| 个人实验 | `experiments` | 用实践检验假设 |
| 领悟 | `mind.reflect` | 反复出现的模式 |
| 卦（今日之卦、问一事、时令之卦） | `yi`、`tianshi` | 一个看处境的角度 |

缺的是：**把它们合成一个判断**——现在的局面是什么，主要矛盾在哪里，下一着落在哪里；以及面对一个选择时，**从多个角度系统地看**。v0.8 补上了这两件事。

## 三、几种看法，各管一段

| 看法 | 它管什么 | 在 LifeOS 里 |
|---|---|---|
| **科学** | 只相信数据；相关不等于因果；看基准率；校准自己的把握 | 全局只用你真实记下的时间、感受、任务、钱；选择分析告诉你"你说七成把握时实际命中几成" |
| **逻辑推演** | 反演、二阶后果、事前验尸、可逆性（单向门/双向门）、最坏情况 | 选择分析的标注与追问 |
| **斯多葛哲学** | 能控制 / 能影响 / 控制不了 | 局势页的三栏；此刻宜里的"写下担心，分三栏" |
| **矛盾论** | 许多矛盾里有一个主要矛盾；矛盾有主要方面；抓住主要矛盾，其他的迎刃而解；主要矛盾会转化 | 自动找出 7 类矛盾、算分量、指出主要方面和"下一着"；每周存快照，主要矛盾变了会告诉你 |
| **实践论** | 认识来自实践，又要回到实践中检验 | 自评（认识）和数据（实践）对不上的地方；每个选择记下预测和把握，到期回看 |
| **论持久战** | 长期目标分战略防御、相持、反攻三阶段；积小胜为大胜；防御阶段不轻易决战 | 冰岛基金、她的三个愿望、Part 3 卡片的阶段；选择涉及某个目标时提醒它在哪个阶段 |
| **量变质变** | 积累到临界点会发生质变 | 进度到 80% 的目标会被点出来："这时候最值得再推一把" |
| **周易** | 时（时令、今日之卦）、位（处境）、势（顺逆） | 天时一栏；扩张性的选择遇到"宜收"的时令会提醒放慢 |
| **命理** | 文化里看"一段时间"的一种语言 | 八字、五行、流年流月的十神主题。**只展示，不进入任何分数**（有测试保证） |

### 矛盾是怎么找出来的

| 矛盾 | 什么时候出现 | 主要方面 | 下一着 |
|---|---|---|---|
| A 与 B 之争 | 两个互相竞争的领域（`relations` 里的 competition），一个投入不足、一个超出 | 投入不足、又是主线的那一边 | 把超出那边的一段固定时间让出来 |
| 工作与她 | 和她的时间低于预算的 70% | 关系 | 守住"和她在一起"的那两个晚上 |
| 想做的事与精力 | 近两周的感受里四成以上是累或低落 | 精力 | 先恢复，只做有期限的 |
| 她的愿望与行动 | 她说出来一个月以上、还只是"想法"的愿望 | 行动 | 挑一个，定日期放进盼头 |
| 资金占用与周转 | 库存接近上限，或滞销两件以上 | 周转 | 滞销的降价出掉 |
| 投入与外面的势 | 主线领域明显逆势 | 外势 | 不加码，守基本盘 |
| 期望与现状 | 主线领域你只给了 4 分以下 | 这个领域 | 从 X 分到 X+1 分的最小一步 |

分量最大的是主要矛盾。同一个"主要方面"只留最重的一条（Part 3 被器材挤、被自媒体挤，说的是同一件事）。

## 四、此刻宜的选择库

`config/moments.toml` 里有 76 条"此刻可以做的事"，分身体、心、她、器材、学、创作、家、外、人、整理、睡，
每一条都标了地利（在哪里做得了）、多久、适合的感受、时候（清晨、午间、黄金时刻、天黑后、周末……）、天气、她在不在身边、和哪些姿态相合。

- **会学习**：你点"好""做完了"的更常出现；点"换一个""现在不想"的慢慢沉下去；36 小时内做过的让一让
- **会长**：你可以在「更多 → 此刻宜的选择库」里加自己的、停用不想要的；每日梳理时 Claude 会根据你最近的生活和季节补 0-3 条（可撤销）
- 自己的库也可以写在 `data/moments.toml`（同 key 覆盖默认的）

## 五、在哪里用

- **网页**：更多 → 🧭 人生局势（主要矛盾、全局与自评、持久战、能控制的事、选择分析、实践检验、天时、命理）；更多 → 🌿 此刻宜的选择库；天时页顶部有入口
- **早安**：每周一会说一句"这周的主要矛盾"
- **每日梳理**：工作包里有局势和你对此刻宜的选择，Claude 写给你的话可以参考它
- **命令行**：`lifeos jushi`、`lifeos jushi rate 关系=8 Part3=4`、`lifeos jushi --ai`、`lifeos choose "问题" -o 选项A -o 选项B`、`lifeos mingli --birth "1997-05-01 08:30"`、`lifeos moments`
- **Siri / Telegram**：`/api/jushi?format=text`、`/jushi`

## 六、诚实的边界

- 局势只看你记下的数据。时间没记、感受没点，它就看不见——这时它会直说"数据还少"
- 分数只是把你自己的判断加起来，不是答案；它帮你想清楚，不替你决定
- 主要矛盾是算法按规则挑的，可能挑错。你觉得不对，就是一个值得想想的信号：是数据没反映现实，还是你的感觉停在了过去
- 命理没有经过科学验证，同样的八字有千千万万人。它在这里只是一种文化语言，不影响任何建议
