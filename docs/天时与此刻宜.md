# 天时 · 地利 · 人和：此刻宜

> 天时不如地利，地利不如人和。——《孟子》

v0.7 给「此刻」加了一张一打开就有的卡片：**此刻宜**。不用先回答任何问题，它按天时、地利、人和推荐你此刻去做什么，并写明理由。
你点一下感受、告诉它你在哪里、她在不在身边，它会更准。

---

## 一、天时：此刻的"时"有好几层

| 层次 | 是什么 | 从哪里来 | 怎么影响建议 |
|---|---|---|---|
| 时辰 | 子丑寅卯……一天里的时候（清晨、午间、黄金时刻、入夜、深夜） | 本机时钟 | 深夜只建议"收一收，去睡吧" |
| 天光 | 日出、日落、黄金时刻（太阳高度 6° 以下）、黄昏 | 按 `[environment]` 的经纬度计算，不用联网 | 天黑后出门的事轻一点；**黄金时刻**在家或在外面，会建议带上相机出去拍 20 分钟 |
| 天气 | 现在和接下来两小时会不会下雨 | Open-Meteo 逐小时预报，每天取一次 | 正下雨时不建议出去走走；天亮且接下来不下雨时，出门的事重一点 |
| 节律 | 你在 `[[blocks]]` 里给自己定的时间（上班、和她在一起、Part 3 时光） | rules.toml | 节律里的事重一点；"和她在一起"的时间，首选"放下手机，好好在一起" |
| 时令之卦 | 这个季节本来的卦（见下） | 节气 | 影响很轻，只有今日之卦的一半 |
| 今日之卦 | 你早上起的那一卦的"姿态" | 起卦 | 和以前一样：只调轻重 |
| 大势 | 各领域的顺势、逆势 | 每日梳理、新闻 | 和以前一样 |

**有期限的事、钱、健康、她：天时永远不改变事实。** 有期限的事不受卦和时令影响；只是如果你人在路上、它需要在家做，会注明"等你回到家时再做"。

### 时令之卦：十二消息卦

起卦是"问"出来的；时令之卦不是起出来的，是这个季节本来的卦。汉代孟喜的卦气说把一年十二个月对应十二个卦，
看阳气怎样从一爻长到六爻，又怎样一爻一爻退去：

```
冬至前后  ䷗ 复   一阳来复      夏至前后  ䷫ 姤   一阴始生
小寒大寒  ䷒ 临   二阳          小暑大暑  ䷠ 遯   二阴
立春雨水  ䷊ 泰   三阳开泰      立秋处暑  ䷋ 否   天地不交
惊蛰春分  ䷡ 大壮 四阳          白露秋分  ䷓ 观   四阴
清明谷雨  ䷪ 夬   五阳          寒露霜降  ䷖ 剥   五阴剥一阳
立夏小满  ䷀ 乾   纯阳          立冬小雪  ䷁ 坤   纯阴
```

现在（霜降）是 ䷖ 剥：阳气只剩最上面一爻。宜收、宜藏，把家和根基安顿好，不宜扩张。
立冬起转为 ䷁ 坤：厚德载物，休养、承载、陪伴。冬至一阳来复。

### 七十二候

每个节气分三候，每候约五天，是古人在黄河流域观察到的物候（《逸周书·时训解》）。
比如霜降三候：豺乃祭兽、草木黄落、蛰虫咸俯。它们不进入任何计算，只是提醒你：此刻在一年里的什么位置。

## 二、地利：你在哪里，这件事要在哪里做

四个地方：🏠 家 · 🏢 公司 · 🚶 外面 · 🚆 路上。

- 你点一下，它记住 3 小时；不点就按节律猜（工作日上班时间在公司，其余时间在家），并标"猜的"
- 每件事需要的地方，从标题和领域推断：
  - "寄快递、超市、看展" → 要出门
  - "打扫、做饭、收纳" → 要在家
  - "改图、上架、复习、写" → 要坐在电脑前
  - "问她、回复、预约" → 手机就能做
  - "拍照、样张" → 要带相机
- 在路上不会建议你打扫厨房；在公司的上班时间，私事往后放

照顾自己的选项（rules.toml 的 `[[now_options]]`）可以写 `need`：leave 出去走走 / camera 带相机 / phone 手机 / home 在家 / any 哪里都行。

## 三、人和：你和她

- **你的感受**：最近 4 小时里点过的感受会被用上；点一下"你现在感觉怎么样"，卡片会马上更新。累了就不推重活
- **她在身边**：点"❤️ 她在身边"（记住 3 小时）：和她有关的事重一点，"给她发消息"这类建议会消失，因为她就在你旁边
- **记忆**：最近常想起的事、她的愿望、这几天没记下和她的事，和以前一样会让相关的事浮上来一点

## 四、卦象解读：不只看卦辞

今日之卦、问一事的结果下面多了一块"展开卦象解读"。都是从六爻的结构推出来的，64 卦、384 爻都能读：

- **内外卦**：内卦（下）是你自己，外卦（上）是你的处境。比如地风升：内巽（入）外坤（顺）——你心思细，想一点点渗透；外面平和，能承载你
- **爻位**：每个变爻所在的位置（初爻开始、三爻转折、五爻主位、上爻过头），是否**得位**（阳爻在阳位）、是否**居中**（二、五爻）、有没有**呼应**（初与四、二与五、三与上阴阳相反）。六爻皆静时看五爻
- **换三个角度看**：
  - 互卦：藏在过程里的，事情往里走会经过什么
  - 综卦：换到对方的位置看，在她、在对方眼里这件事是什么样
  - 错卦：完全反过来的处境
- **落在各处**：这一卦的姿态落在工作、她、器材、身体、学习上，分别是什么意思

它们给你角度，不给结论。

## 五、在哪里用

- **此刻页**：顶部的"🧭 此刻宜"
- **天时页**：最上面的"🌗 时令"（时令之卦、三候、日出日落、此刻）；今日之卦和问一事下面的"展开卦象解读"
- **早安**：多了时令之卦、这一候、日出日落和黄金时刻
- **每周的信**：多了"天时"，节气或时令之卦要换的时候提前告诉你
- **每日梳理**：工作包里有天时，Claude 写给你的那句话可以自然地借用时令
- **命令行**：`python3 -m lifeos now`（此刻宜，可加 `--place 外面 --her`）、`python3 -m lifeos tian`（天时）
- **Siri**：`/api/right_now?format=text`（见 iPhone 使用指南第 7 步）
- **Telegram**：`/now`、`/now 疲惫 家`、`/tian`

## 六、可以调的

- 位置与城市：`data/rules.toml` 的 `[environment]`（`latitude`、`longitude`、`city`）。日出日落按你电脑的时区显示
- 卦对建议的影响：`[yi] weight`（0 = 只看不影响）。时令之卦的影响是它的一半
- 照顾自己的选项和它们需要的地方：`[[now_options]]`
