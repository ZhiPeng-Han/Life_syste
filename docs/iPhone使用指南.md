# 📱 在 iPhone 上使用 LifeOS

## 先理解一件事

LifeOS 运行在**你的电脑**上：数据和"大脑"都在电脑里。**iPhone 是遥控器**：通过浏览器和快捷指令访问它。

```
  iPhone（主屏幕上的 LifeOS 图标 / Siri "记一下"）
        │  家里 Wi-Fi，或者在外面通过 Tailscale 加密连接
        ▼
  你的电脑（运行 LifeOS，数据只存在这里）
```

所以：**电脑开着、LifeOS 在运行，iPhone 才能用。** 想 24 小时可用，见最后一节。

整个设置大约 30 分钟，只需要做一次。

---

## 第 1 步 · 电脑上装 Python（5 分钟）

需要 Python **3.11 或更新**。

**Mac**
1. 打开 <https://www.python.org/downloads/>，下载最新版，双击安装
2. 打开「终端」（启动台 → 其他 → 终端），输入 `python3 --version`，看到 `Python 3.11` 或更高就对了

> Mac 自带的 python3 可能是 3.9，版本太旧，一定要从 python.org 装新版。

**Windows**
1. 同样从 python.org 下载安装。**安装第一屏勾选 "Add python.exe to PATH"**
2. 打开「命令提示符」，输入 `python --version` 检查

## 第 2 步 · 把 LifeOS 下载到电脑（3 分钟）

1. 在电脑浏览器打开你的 GitHub 仓库 `ZhiPeng-Han/Life_syste`
2. 左上角分支下拉菜单，选择 **`claude/ai-life-management-system-u5d0b3`**（代码在这个分支上）
3. 点绿色 **Code** 按钮 → **Download ZIP**
4. 解压，把文件夹改名为 `LifeOS`，放到「文稿」(Documents) 里

> 会用 git 的话也可以：`git clone -b claude/ai-life-management-system-u5d0b3 https://github.com/ZhiPeng-Han/Life_syste.git ~/Documents/LifeOS`
> 以后系统更新时，`git pull` 就能拿到新版本，不用重新下载。

## 第 3 步 · 启动（2 分钟）

**Mac**：在 LifeOS 文件夹里双击 **`start-lifeos.command`**。
- 第一次如果提示"无法打开，来自身份不明的开发者"：**右键 → 打开 → 打开**
- 如果提示没有权限：打开终端，输入 `chmod +x ~/Documents/LifeOS/start-lifeos.command` 后再双击
- 如果弹出"是否允许 Python 接受传入网络连接"：点 **允许**

**Windows**：双击 **`start-lifeos.bat`**。如果 Windows 防火墙弹窗，勾选"专用网络"并允许。

窗口里会显示：

```
📱 LifeOS · iPhone 模式

  在家（同一个 Wi-Fi）：  http://192.168.1.23:8765/?token=xxxxxxxx
  快捷指令里用的口令（请求头 X-LifeOS-Token）：xxxxxxxx
  ☕ 已阻止电脑睡眠（关掉这个窗口就恢复）
```

**这个窗口不要关**，关了 iPhone 就连不上了。第一次启动时，系统会自动写入她的三个愿望和起步任务。

## 第 4 步 · iPhone 添加到主屏幕（3 分钟）

1. 确认 iPhone 和电脑连着**同一个 Wi-Fi**
2. 把窗口里"在家"那行链接发到 iPhone：
   - Mac：在电脑上复制，iPhone 上直接粘贴（"通用剪贴板"，同一 Apple ID 自动可用）
   - 或者用隔空投送、发给自己的备忘录
3. 在 iPhone 的 **Safari** 里打开这个链接（必须是 Safari）
4. 点底部的 **分享按钮**（方框加向上箭头）→ 往下滑 → **添加到主屏幕** → 添加

主屏幕上会出现一个 LifeOS 图标（橙色底、镜头图案）。点开就是全屏 App，不再显示浏览器地址栏。

## 第 5 步 · 在外面也能用：Tailscale（10 分钟，强烈推荐）

第 4 步的链接只在家里 Wi-Fi 下有效。Tailscale 会在你的电脑和 iPhone 之间建一条**加密的私人通道**，在公司、地铁、旅行中都能连回家里的电脑，而且不需要把电脑暴露到公网。个人使用免费。

1. **电脑**：在 <https://tailscale.com/download> 下载安装（Mac 也可以在 App Store 搜 Tailscale），用 Google 或 Apple 账号登录
2. **iPhone**：App Store 搜索 **Tailscale**，安装，用**同一个账号**登录，按提示允许添加 VPN 配置
3. 回到电脑，关掉 LifeOS 窗口，再双击启动一次。窗口里会多出一行：
   ```
   在外面（Tailscale）：  http://100.x.y.z:8765/?token=xxxxxxxx
   ```
4. 在 iPhone Safari 打开**这一行的链接**，再"添加到主屏幕"一次，然后删掉第 4 步加的那个图标

以后**只用 Tailscale 这个图标**：在家、在外都能用（iPhone 上的 Tailscale 保持开启即可）。

## 第 6 步 · Siri："嘿 Siri，记一下"（5 分钟，最常用）

这是整个系统里最重要的一个入口：**任何时候想到什么，说一句话就进入记忆系统。**

打开 iPhone 的 **快捷指令** App → 右上角 **+**，依次添加 3 个操作：

1. 搜索并添加 **「听写文本」**（Dictate Text），点它把语言设为 **中文（中国大陆）**
2. 搜索并添加 **「获取 URL 的内容」**（Get Contents of URL）
   - URL 填：`http://100.x.y.z:8765/api/capture?format=text`（用你自己的 Tailscale 地址）
   - 点 **显示更多**：
     - 方法：**POST**
     - 头部：添加一个，键 `X-LifeOS-Token`，值填窗口里显示的**口令**
     - 请求体：**JSON** → 添加新字段 → 类型「文本」，键 `text`，值点一下选择变量 **「听写的文本」**
3. 搜索并添加 **「显示结果」**（想听语音回复就换成「朗读文本」）

最上面把快捷指令命名为 **记一下**，完成。

现在试试：**"嘿 Siri，记一下"** → 说"今天 180 收了一支 50/1.4 有轻微雾，她说想去看极光" → 你会看到：

```
🧠 记住了 2 条
❤️ 她的愿望：想去看极光
📷 收入 50/1.4 £180 → L-2026-001
```

> 想打字而不是说话：把第 1 个操作换成 **「要求输入」**。还可以把这个快捷指令加到主屏幕或锁屏小组件上。

## 第 7 步 · 早上自动推送今日安排（3 分钟）

**先做快捷指令「今天安排」**：新建快捷指令 → 添加 **「获取 URL 的内容」**
- URL：`http://100.x.y.z:8765/api/today?format=text`
- 显示更多 → 方法 **GET**，头部 `X-LifeOS-Token` = 口令

再添加 **「显示结果」**，命名为 **今天安排**。

**再设成每天早上自动运行**：快捷指令 App 底部 **自动化** → **+** → **特定时间** → 07:30、每天 → 选择 **立即运行** → 选「今天安排」。

另外两个可选的：
- **「她」**：同样做法，URL 换成 `.../api/her?format=text`，Siri 说"她"，就会给出今天的惊喜建议
- **晚间签到提醒**：自动化 → 22:10 → 操作选「打开 URL」，填你的 LifeOS 链接 → 打开后滑到「今日」页底部的签到表单

## 每天怎么用（iPhone 版）

| 时间 | 做什么 | 在哪 |
|---|---|---|
| 07:30 | 自动弹出今天 3 件事 + 时间块 | 自动化 |
| 随时 | 想到什么就说 | "嘿 Siri，记一下" |
| 遇到捡漏 | 输入型号、报价、瑕疵 → 收不收 | LifeOS →「器材」→ 捡漏评估 |
| 收货/上架/卖出 | 点卡片上的按钮推进 | LifeOS →「器材」→ 库存流水线 |
| 约会前 | 看今天的惊喜建议 | LifeOS →「她」 |
| 22:10 | 3 分钟签到 | LifeOS →「今日」最下方 |
| 周日晚 | 看周复盘、平衡轮 | LifeOS →「复盘」 |

每条建议旁边的 👍 ✏️ 👎 **一定要点**。系统就是靠这些反馈学习你的，反馈越多，替你做的决定越多。

## 打不开？对照这里

| 现象 | 原因与解决 |
|---|---|
| 一直转圈 / 无法连接 | ① 电脑睡着了，或 LifeOS 窗口被关了；② 不在家又没开 Tailscale；③ 换了 Wi-Fi，电脑的局域网地址变了，重启 LifeOS 看新链接（用 Tailscale 地址就不会变） |
| 显示"需要 token" | 链接里少了 `?token=...`，用窗口里的完整链接重新打开并添加到主屏幕 |
| 快捷指令显示 unauthorized | 头部 `X-LifeOS-Token` 的口令填错了 |
| Mac 合上盖子就断 | 合盖会强制睡眠。保持开盖（可以把屏幕亮度调到最低），或接电源 + 外接显示器 |
| 想换口令 | 删除 `LifeOS/data/token.txt`，重启，然后重新添加主屏幕图标并更新快捷指令 |

## 安全须知

- 带 `token` 的链接和口令 = **你人生数据的钥匙**，不要发给任何人（给她看器材橱窗，可以在你手机上打开 `/shop` 给她看）
- 在外面只用 **Tailscale** 连接，**不要**在路由器上做端口映射把它暴露到公网
- 数据都在电脑的 `LifeOS/data/` 里：定期把这个文件夹复制到移动硬盘或 iCloud 做备份
