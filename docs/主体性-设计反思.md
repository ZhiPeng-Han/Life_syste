# 人是生活的主体，不是被管理的系统

> v0.2 的设计反思。写给 Zhipeng，也写给以后迭代这个系统的任何人（包括 AI）。

## 你说得对

回头看 v0.1，它有一种不自觉的傲慢：

- 打开它，第一眼是一张从 07:00 排到 22:15 的时间表。**昨天的你替今天的你做好了所有决定。**
- 和她在一起的时间叫"受保护块"，还写着"手机静音"。**爱被写成了一项需要执行的任务。**
- 到处是"预算""采纳率""自主等级""时薪"。**这是管理一台机器的语言，不是陪伴一个人的语言。**
- 没做完的事会变成"排不下""滞销""逾期"。**每打开一次，就被提醒一次自己不够好。**

这就是你说的恶性循环：计划越细，未来越被控制；做不到计划，就愧疚；愧疚了，就想用更细的计划弥补。

而人最宝贵的是**当下**：此刻的感受，此刻想做的事，此刻身边的人。一张 dashboard 永远无法替你感受。

## 那系统还有什么用？

想清楚之后，我认为一个好的系统只该做两件事：

1. **替你记住**：杂事、她说过的话、发生过的美好，让你不用把它们一直挂在心上。**记忆是为了让你放心地活在当下，而不是为了被管理。**
2. **在你需要时，帮你做个小决定**：当你累了、不想想、站在原地犹豫时，你**主动**问它"现在做什么"，它给你一个，你可以说不。**决定权是你"拉"过来的，不是它"推"给你的。**

除此之外，它应该安静。

## v0.2 的十条新原则

1. **此刻优先。** 打开系统，第一个问题不是"今天的日程"，而是"你现在怎么样？"
2. **感受是正当的理由。** 累了就是累了，不需要被"优化"。疲惫的时候，系统会建议休息、散步、给她发条消息，而不是塞给你一件"低能量任务"。
3. **可能性，不是命令。** 系统每次只给一个建议，永远附带"换一个"和"什么都不做也很好"。
4. **决定是你拉过来的。** "帮我决定"是一个按钮，你按了它才替你选。
5. **口袋，不是待办清单。** 杂事装进口袋，它们会等你，不会追你。没有红色的逾期标记。只有真正有外部期限的事（比如甲方要的图），才会温和地浮到上面。
6. **可以放下。** 一件事你跳过了三次，系统会问："它还重要吗？要不要放下？"放下不是失败，是选择。
7. **记录做过的，不追究没做的。** 周末收到的是一封信，写这一周的瞬间、她、你做到的事，不是一张成绩单。
8. **节律，不是日程。** 和她的晚上、周日的慢时光，是生活的节奏，像呼吸，不是时间格子。
9. **结构是你选的工具。** 有些日子你确实需要结构（交图前、考试前），那就点"今天我需要一点结构"，时间表会出现。其余的日子它不出现。
10. **默认安静。** 不主动打扰。早上一段简短的问候，其余时候，你不来找它，它就不说话。

## 具体改了什么

| v0.1 | v0.2 |
|---|---|
| 首页：今日驾驶舱（时间表 + 3 件事 + 提醒） | 首页：**此刻**。先问你感觉怎么样、有多少时间，再给一个可能性 |
| 待办列表，带优先级和截止日 | **口袋**：杂事放在这里，按需取用，可以放下 |
| 周复盘：时间账本、采纳率、平衡轮 | **一封信**：这周的瞬间、她、你做到的事、一个问题。数据还在，但收进"更多"里 |
| 早上推送完整时间表 | 早上一段问候：今天的节律、真正有期限的事、一个**回响**（她三周前说过的话） |
| 晚间签到：能量 1-10、心情 1-10、睡眠时长 | **晚安**：此刻的感受（点一下）、今天值得记住的瞬间、她今天怎么样 |
| "受保护：和她的时间（手机静音）" | "和她在一起" |
| 决策自主等级 L0–L4 | "交给它的小事"：你愿意交出去的，只有菜单、发货日这类琐事 |

底层的记忆、决策引擎、器材生意模块都还在。它们从"前台"退到了"后台"：**为你服务，但不站在你面前指挥你。**

## 给以后的迭代

每加一个新功能前，先问三个问题：

- 它是帮他**记住**，还是在**要求**他？
- 它让他更**在场**，还是更**焦虑**？
- 如果他今天什么都不想做，这个功能会不会让他感到愧疚？

如果答案不对，就不要做。
