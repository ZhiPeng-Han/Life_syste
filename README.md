# Life_syste · LifeOS

一个基于 AI 的多维度人生管理系统：以**记忆**为根基、以**关系网络**为骨架、以**决策减负**为目标、能**持续自我迭代**。

📄 **完整方案**：[docs/LifeOS-方案.md](docs/LifeOS-方案.md)

## 核心模块

- **记忆系统**：情景 / 语义 / 程序 / 前瞻 / 价值五类记忆，日→周→月→年逐级巩固
- **关系引擎**：发现人生各条线之间的因果、竞争、协同、依赖关系
- **决策引擎**：L0–L4 自主等级，逐步把简单决策交给系统
- **领域模块**：建筑工作、Part 3、器材事业、AI 自媒体、感情经营、生活维持、健康、旅行、阅读与人生导则
- **可视化**：今日驾驶舱、人生星图、时间河流、平衡轮、业务看板
- **自我迭代**：每日签到、周复盘、个人实验、"我的说明书"

> ⚠️ 个人数据请放在 `data/` 目录，该目录已被 `.gitignore` 排除，切勿提交。
