# 本地部署 · 和 GitHub 同步 · 每日 AI 梳理（不用 API）

这份文档讲三件事：

1. 把 LifeOS 装在你的 Mac 上，开机自动运行，iPhone 随时能用
2. 系统代码和 GitHub 保持同步，你的个人数据永远留在本机
3. 不用 API key：每天由你电脑上的 **Claude Code** 定时做一次 AI 梳理

```
                ┌──────────── GitHub（私有仓库，只有代码）────────────┐
                │      git pull ↓                     ↑ git push       │
                └─────────────────────────────────────────────────────┘
  你的 Mac
  ├─ LifeOS 服务（开机自动运行）  ←── iPhone / Siri / Telegram 随手记
  │     data/lifeos.db（你的人生数据，不进 git，每天自动备份）
  │
  └─ Claude Code 定时任务（每天 07:30，用你的 Claude 登录，不用 API key）
        1. git pull，拿最新代码
        2. python3 -m lifeos ai prepare  → 工作包：新输入 + 新闻标题 + 上下文
        3. Claude 读工作包，上网看今天的大事，梳理、关联、总结、提建议
        4. python3 -m lifeos ai apply    → 校验后写入，每处改动都能撤销
```

## 一、第一次安装（大约 15 分钟）

### 1. 准备三样东西

| 需要 | 怎么检查 / 安装 |
|---|---|
| Python 3.11 或更新 | 终端输入 `python3 --version`。太旧就到 python.org 下载安装 |
| Git | 终端输入 `git --version`。没有的话 macOS 会提示你安装"命令行开发者工具"，点安装 |
| Claude 桌面版 | claude.ai/download 下载，用你的 Claude 账号登录。每日梳理用的是它的 **Code** 标签页 |

### 2. 把仓库克隆到电脑上

仓库是私有的，需要登录 GitHub。最省事的两种方式，选一种：

**方式 A：GitHub Desktop（不用记命令）**
1. 下载 desktop.github.com，登录你的 GitHub 账号
2. File → Clone repository → 选 `ZhiPeng-Han/Life_syste`，位置选你的用户目录，比如 `~/LifeOS`
3. 克隆好以后，顶部 Current branch 切换到 `claude/ai-life-management-system-u5d0b3`

**方式 B：终端**
```bash
cd ~
git clone -b claude/ai-life-management-system-u5d0b3 https://github.com/ZhiPeng-Han/Life_syste.git LifeOS
```
第一次会要你登录 GitHub（密码处填 GitHub 的 Personal Access Token，或者先装 `gh` 再运行 `gh auth login`）。

> **以前下载过 ZIP 版本？** 把旧文件夹里的 `data/` 整个复制到新的 `~/LifeOS/data/`，你的数据就跟过来了。

### 3. 装成开机自动运行

```bash
cd ~/LifeOS
bash scripts/install-mac.sh
```

它会：
- 找到合适的 Python
- 初始化数据库
- 让 LifeOS 在后台运行，登录后自动启动，崩溃了自动重启
- 打印 iPhone 用的链接（带口令），在 iPhone Safari 打开 → 分享 → 添加到主屏幕

> 服务运行期间会阻止电脑"闲置睡眠"，这样 iPhone 随时能连上。合上笔记本仍会睡眠。
> 不想常驻？不用装，需要时双击 `start-lifeos.command` 就好。
> 卸载：`bash scripts/install-mac.sh --uninstall`（数据不会动）。

在外面用：装 Tailscale，见 [iPhone使用指南](iPhone使用指南.md) 第 4 步。

## 二、和 GitHub 同步

### 代码：自动拉取

以下三个地方都会自动 `git pull`，你基本不用管：
- 每天早上的每日梳理，第一步就是拉取最新代码
- 双击 `start-lifeos.command` 启动时
- 手动：`bash scripts/update.sh`（顺便备份数据库，并重启后台服务）

后台服务发现代码更新后，会在 5 分钟内自己重启，加载新版本。

### 你的个人设置：放在 data/rules.toml

**不要直接改 `config/rules.toml`**，否则更新时会冲突。在 `data/rules.toml` 里只写你想改的部分，它会叠加在默认设置上：

```toml
# data/rules.toml —— 只写想改的
[environment]
city = "曼彻斯特"
latitude = 53.48
longitude = -2.24

[ai]
mode = "daily"

[telegram]
morning = "07:45"
```

仓库以后新增的设置项会自动生效；`[[blocks]]` 这类列表整体以你写的为准。

### 你的数据：永远不进 git

`data/` 目录（数据库、信、备份、梳理记录）被 `.gitignore` 排除，不会上传到 GitHub，哪怕仓库是私有的。

备份：
- 每次每日梳理前自动备份到 `data/backups/`（保留最近 30 份）
- 手动备份：`python3 -m lifeos backup`
- 想多一层保险，可以定期把 `data/` 复制到 iCloud Drive 或移动硬盘

### 双向：你也可以改代码

在本机 Claude Code 里改了代码（比如实现一条"系统提升建议"），像平常一样 commit、push 到同一个分支。下次我在云端改动时会先拉取你的修改。

## 三、每日 AI 梳理：Claude Code 定时任务

### 它每天做什么

| | 做什么 | 结果出现在 |
|---|---|---|
| 🌏 天下大势 | 读新闻源 + 上网搜几个公共话题（英国建筑市场、利率、二手相机、AI 视频、冰岛），挑出真正影响你的 0-5 条，标顺势/逆势；过时的大势退场 | 天时页、早安、此刻建议的"势" |
| 🧭 顺势而为 | 一两句：今天外面的势对你意味着什么 | 天时页、早安 |
| 🧠 数据梳理 | 对照你的原话，修正规则引擎分错的领域、类型、发生时间；补上情绪和主题；确认它能看懂的"等确认"记忆 | 记忆、星图、所有建议 |
| ✨ 关联 | 事物之间的关系（陶艺 ↔ 冰岛：都是她想和你一起体验的事） | 星图、回忆 |
| 💡 领悟 | 最多 3 条跨越多条记忆的规律，每条带证据 | 记忆页、早安、信、AI 的核心记忆 |
| 📝 总结 | 这段时间的 3-5 句总结 | 日摘要（回忆时会用到） |
| 💬 给明天的话 | 早安一句、关于她的一个小提醒 | 此刻页顶部、她页、早安 |
| ✉️ 周日的信 | 这一周的信 | 信页 |
| 🛠 系统提升建议 | 系统哪里不懂你、哪里多余、哪里可以更好，0-3 条 | 更多 → 系统提升建议 |

它**不能**：删除你的记忆、改代码、改设置、提交或推送到 GitHub。所有改动都记录在案，可以整次撤销。

### 设置（Claude 桌面版，推荐）

1. 打开 Claude 桌面版 → 左上角切到 **Code** 标签
2. 侧边栏点 **Scheduled**（或在 **More** 菜单里）→ **New task**
   - 如果弹出 **Create with Claude / Set up manually**，选 **Set up manually**
3. **Name**：`lifeos-daily`
4. **指令框**里填：
   ```
   按照 scripts/lifeos-daily.md 里的说明，做今天的 LifeOS 每日梳理。
   ```
5. 展开 **Advanced settings** → 打开 **Only on this computer** → **Local folder** 选 `~/LifeOS`
6. **Trigger** 选 **Daily**，时间 `07:30`（你起床前）
7. 指令框下方的权限模式保持默认，模型用默认即可 → **Create**
8. **重要：** 在任务页面点 **Run now** 跑一次，看着它。它请求权限时（运行 `python3 -m lifeos ai …`、`git pull`、写 `data/ai/outbox/…`、WebSearch、打开新闻网站），选 **Always allow**。之后每天就不会再卡住
9. 设置 → **Desktop app**（或 **This computer → System**）→ 打开 **Keep computer awake**，避免电脑睡过了时间

如果当天电脑没开，醒来后会补跑一次。

> 界面名称可能随版本变化（旧版本叫 **Routines / New routine**）。以 Claude Code 官方文档为准：
> https://code.claude.com/docs/en/desktop-scheduled-tasks

### 设置（备用：命令行 + launchd）

不用桌面版，或者想让它在后台静默运行：

```bash
# 先确保装了 Claude Code 命令行，并登录过一次（在终端运行 claude，按提示登录）
cd ~/LifeOS
bash scripts/install-mac.sh --daily     # 每天 07:30 运行 scripts/daily-claude.sh
```

需要的权限已经在 `scripts/daily-claude.sh` 里逐项列出（只允许 `lifeos ai` 命令、写 `data/ai/`、搜索和几个新闻网站），没列出的一律拒绝。日志在 `data/logs/`。

### 每天看什么

什么都不用看。想看的话：
- **此刻页顶部**：💬 早安的一句话
- **更多 → 每日梳理**：今天改了什么；**系统提升建议**：点"想要"或"不用"
- 报告：`data/ai/reports/<日期>.md`

### 不满意？

```bash
python3 -m lifeos ai undo          # 撤销最近一次梳理的全部改动
python3 -m lifeos ai status        # 看最近一次的情况
```

还可以直接改 `scripts/lifeos-daily.md`，比如"多关注 Part 3 考试动态""少写领悟"。下一次运行就会按新的说明做。

### 把"想要"的建议变成真的

在本机打开 Claude Code，在 `~/LifeOS` 里说：

```
看一下 python3 -m lifeos ai improvements --all 里我标记为 accepted 的建议，挑一条实现，跑测试，然后 commit 并 push。
```

改动会推送到 GitHub。

## 四、AI 的三种方式

在 `data/rules.toml` 的 `[ai] mode` 里选：

| mode | 意思 | 需要 |
|---|---|---|
| `auto`（默认） | 设置了 `ANTHROPIC_API_KEY` 就实时调用 API；没有就只靠每日梳理 | 什么都不用 |
| `daily` | 不实时调用任何 AI，只靠每日梳理 | 什么都不用 |
| `claude-code` | 除了每日梳理，在你主动点的地方（写信、问卦解读、惊喜方案、说明书）调用本机的 `claude` 命令 | 本机装了 Claude Code 命令行并登录 |

随手记一句话时，**永远不会**等 AI：规则引擎立刻记下，第二天早上的梳理再帮你修正。这样 iPhone 上记东西总是秒回。

> 每日梳理和 `claude-code` 模式用的是你 Claude 订阅的额度，不另外收 API 费用。

## 六、常见问题

**iPhone 打不开了？** 电脑是不是睡着了或者换了 Wi-Fi。终端运行 `tail -20 ~/LifeOS/data/logs/server.log` 看日志；重新运行 `bash scripts/install-mac.sh` 会打印新的链接。

**`git pull` 失败？** 多半是你直接改过仓库里的文件。运行 `git status` 看看是哪个，把个人设置挪到 `data/rules.toml`，然后 `git checkout -- <那个文件>`。

**梳理没有运行？** 在桌面版的任务页面看 **History**，悬停在跳过的记录上会显示原因（电脑睡着、上一次还没结束等）。

**会不会把我的隐私发到网上？** 每日梳理的说明里写明：上网搜索只搜公共话题，绝不把你的记忆或她的事放进搜索词。你的数据只在本机和 Claude 之间（和你平时用 Claude 一样）。
