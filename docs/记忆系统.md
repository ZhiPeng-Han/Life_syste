# 记忆系统：在后台记着、连着，影响每一处

> 你说：记忆是一个复杂的整体。不需要每条都摊开给你看，需要的是在后台做好系统性记录，并影响到各个方面。

这份文档说明 v0.5 的记忆是怎么工作的。你平时什么都不用做：随手说一句、晚上说晚安，剩下的它自己完成。

---

## 一、一句话进来之后

```
"前天她又说起陶艺，说周末的体验课好像很治愈"
  │
  ① 原话永久保留（raw_inputs），之后怎么理解都可以回到原话
  │
  ② 拆解：记忆 / 待办 / 她的愿望 / 器材买卖
  │    每条记忆：类型、领域、重要性、把握度、情绪、涉及的人、涉及的事物
  │
  ③ 时间：事情发生在"前天"，不是今天 —— 发生时间和记下时间分开
  │
  ④ 连接：挂到「她」「关系」「陶艺」这几个节点上
  │    同一个「陶艺」节点上，还连着她的愿望、你查过的体验课、为它起过的卦……
  │
  ⑤ 更新：如果这是一条新的事实，并且推翻了旧的，旧的变成"曾经是"
  │
  └→ 晚安之后：巩固成日摘要 → 反思，看出更高一层的规律
```

## 二、五种记忆

| 类型 | 是什么 | 例子 | 主要用在 |
|---|---|---|---|
| 经历 episodic | 发生过的事 | 和她在泰晤士河边散步 | 回响、信、回忆 |
| 事实 semantic | 关于人的稳定事实 | 她不吃香菜 | 核心记忆、惊喜方案、说明书 |
| 方法 procedural | 怎么做 | 发快递前先拍包装照 | 回忆 |
| 打算 prospective | 将来要做的 | 下周要出施工图 | 口袋 |
| 原则 normative | 你相信什么 | 先保护和她的时间 | 人生导则 |

另外有两种由系统生成：**日摘要**（每晚一条）和**领悟**（从许多条记忆里看出的规律）。

## 三、一张网，不是一个列表

系统认识的"事物"会自己长出来：
- 她的愿望里提到的（"想学陶艺" → 陶艺）
- 盼头、去过的地方、器材型号（50/1.4、A7M3）
- 起始的几个：冰岛、极光、减肥、转售平台（`config/rules.toml` 的 `[memory] topics`）

之后任何一句话、一个待办、一次问卦，只要提到它们，就自动挂上去。所以"冰岛"这个节点上会有：
她第一次说想去的那天、冰岛基金攒了多少、盼头还有几天、口袋里和冰岛有关的事、你为"冬天去合适吗"起的卦。

想看的时候：`python3 -m lifeos mind about 冰岛`。

## 四、回忆：AI 开口之前先想起

以前 AI 回应你时，只看"最近 15 条记忆"。半年前她说过的一句关键的话，它想不起来。

现在每次 AI 开口前，先**回忆**：

> 分数 = 时近性 + 重要性 + 字面相关 + **网上相连** + 类型（领悟、事实优先）

比如你问卦"周末给她什么惊喜"，它会想起：她三次提到陶艺（领悟）、她不吃香菜（事实）、上周六她给你看的陶艺视频，还有关于陶艺的所有记录。

用到回忆的地方：此刻的一两句回应、问一事、惊喜方案、每周的信。

## 五、领悟：从许多条里看出一条

借鉴 Generative Agents 的 reflection。每晚说完晚安，它会看一看：

- **反复出现的事**："这一个月里，和她有关的记忆 3 次提到「陶艺」。说了几次的事，往往比说出口的更重要。"
- **和她之间的安静**："过去 10 天你记下了 12 件事，没有一件和她有关。也许只是没记，也许值得留意。"
- **累的日子常和什么在一起**："你感觉累或烦的那些天，记忆里「建筑工作」特别多。不一定是它让你累，但它们常常一起出现。"
- **好的日子常和什么在一起**："这也许是你的一处源泉。"
- 配置了 Claude 时，每周再深想一次，最多 3 条，每条都必须引用作为证据的记忆。

三条规则：
1. 每条领悟都有证据，不凭空下判断
2. 你说"不对，别再提"，它就永远不再提（Claude 也会被告知）
3. 规律不再成立时（比如你记下了和她的事），那条领悟自动淡出

## 六、它影响的地方

| 地方 | 记忆怎么影响它 |
|---|---|
| **此刻** | 最近常想起的事、和她的愿望有关的事、这几天没记下和她的事时与她相关的事，会浮上来一点；常和累的日子一起出现的事，在你累的时候沉下去一点。都会写明原因。**有期限的事不受影响** |
| **捡漏评估** | "🧠 你记过：那支 50/1.4 挂了好久都卖不动"。只提醒，**结论仍由数据决定** |
| **问一事** | 解卦时带着和这件事相关的记忆与事实 |
| **惊喜方案** | 带着关于她的事实、领悟和愿望 |
| **每周的信** | 新增"这周我注意到的" |
| **早安** | 有新领悟时，说一句"我注意到" |
| **我的说明书** | 新增"系统从记忆里领悟到的" |
| **每一次 AI 回应** | 核心记忆里常驻"它知道的"：领悟 + 稳定事实（被取代的不在其中） |

## 七、人会变

"她喜欢吃寿司" → 半年后 "其实她现在不喜欢吃寿司了"。
新的事实取代旧的，旧的标为"曾经是"，**不删除**。它不再进入回忆和核心记忆，但一个人是怎么变的，还留在那里。

## 八、你需要做的

什么都不用。如果想：
- 「更多 → 🧠 记忆」：搜一件事，或者否定一条领悟
- `python3 -m lifeos mind`：看现在的领悟
- `python3 -m lifeos mind recall 一句话`：看它会想起什么
- `python3 -m lifeos mind reflect --ai`：让 Claude 现在就想一想

## 九、还没做到的

- **语义相关**仍然靠字面和连接。"北边看极光"能通过"极光"连到冰岛，但完全换一种说法时可能想不起来。下一步可以在有 Claude 时做查询扩展
- **两个人的视角**：现在记的是你的视角。如果她也愿意用，可以有"我们"的记忆
- 规则引擎对领域的判断仍然粗糙；配置 Claude 后会准确很多
